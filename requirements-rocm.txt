# requirements-rocm.txt — runtime-зависимости для AMD ROCm.
#
# Используется вместо requirements.txt при сборке образа с DEVICE=rocm
# (см. build-arg в Dockerfile и docker-compose.yml).
#
# ⚠️ Версия onnxruntime-rocm ЖЁСТКО привязана к версии ROCm на хосте
#    (https://onnxruntime.ai/docs/execution-providers/ROCm-ExecutionProvider.html):
#      onnxruntime 1.22.x → ROCm 7.0   (PyPI, ищет libhipblas.so.3)
#      onnxruntime 1.21   → ROCm 6.4   (AMD repo, ищет libhipblas.so.6) ← наш хост
#      onnxruntime 1.19   → ROCm 6.3
#    На хосте ROCm 6.4 (/opt/rocm-6.4.0). Версии под 6.4 НЕТ на PyPI — AMD
#    публикует их только на repo.radeon.com. Берём wheel по прямому URL.
#    Доступные теги: cp310, cp312 (cp311 НЕТ) → образ собран на Python 3.12.
#    Несовпадение версий = "Failed to load libonnxruntime_providers_rocm.so:
#    libhipblas.so.X: cannot open shared object file" и тихий откат на CPU.
#    (EP удалён из onnxruntime с 1.23 — выше 1.22 поднимать нельзя.)
# ИСПРОБОВАНО: onnxruntime-rocm==1.22.2.post3 с PyPI падал с libhipblas.so.3.
#
# ⚠️ Колёса onnxruntime-rocm несовместимы с numpy>=2 — фиксируем numpy<2
#    (вместо numpy==2.0.2 из requirements.txt).
#
# ВНИМАНИЕ: здесь НЕ подключаем `-r requirements.txt` — там закреплён
# onnxruntime==1.20.1 (CPU), он конфликтует с onnxruntime-rocm. Список
# дублируется полностью, с заменой onnxruntime → onnxruntime-rocm.
